# Sunlit Quest · P0 / P1 界面素材包 v1

本批使用 **内置 image_gen** 生成六张新原始图集，参考项目已选的「明亮冒险②」海军蓝、暖金、青绿像素风。完整提示词、生成工具和原始文件来源记录在 `prompts.json`。没有使用外部图片 API，也没有覆盖旧素材。

## 文件与内容

- `preview.html`：双击打开的离线预览，包含三层面板的九宫格拉伸、按钮状态切换、天赋节点与现有图标的组合、深浅背景检查和四组动画播放。文字全部由页面绘制，不在素材中。
- `preview.png`：六组静态总览；`preview-*.png` 是分组详图。
- `originals/`：六张 1536 × 1024 原始 PNG，全数保留。
- `export/`：55 张独立 PNG、55 张无损 WebP，另有 4 条 WebP 动画帧带。
- `manifest.json`：尺寸、分组、切片边距、透明插槽、动画帧顺序和中心点。
- `manifest.js`：相同清单，供本地文件预览直接读取，不依赖 fetch 或服务。

| 优先级 | 分组 | 独立素材数量 | 内容 |
|---|---|---:|---|
| P0 | panels | 6 | 主面板、内嵌层、阅读层各一张边框和一张底纹 |
| P0 | buttons | 5 | 普通、按下、选中、禁用、危险操作 |
| P0 | talents | 12 | 小节点、重要节点、核心节点各三态；三种状态连线 |
| P1 | navigation | 8 | 角色属性、套装、天赋、技能配置、商店、打造、整理、分解 |
| P1 | ornaments | 8 | 四角花、分隔线、标题左右端、章节徽记 |
| P1 | feedback | 16 | 选中微光、装备成功、天赋点亮、点击反馈，各四帧 |

## 整理方式

用户此前允许用脚本去除生成背景、切分和清理边缘，本批沿用该方式。第一张图集未生成真实透明通道，灰白棋盘格按颜色去除；后五张采用纯洋红底，按色键去除并清理紫边。没有把棋盘格作为透明素材交付。

`prepare.py` 使用 Python 3.12 + Pillow：

```powershell
py -3.12 art/sunlit-ui/interface-kit-v1/prepare.py
```

按实际空白行分割按钮和节点，避免模型没有严格遵循网格导致裁切。使用最近邻统一逻辑像素密度并约束调色板。按钮外尺寸统一 576 × 80；动画帧采用每行共用裁切范围和缩放，不对每帧单独放大，以保留扩散大小变化。导出后使用独立预览检查透明孔、边缘和尺寸。

## 后续接入约定

- 已接入游戏。运行时仅使用 `public/assets/ui/sunlit/interface-kit/` 中的 WebP；原图和 PNG 继续留在 `art/`，不进入加载清单。动画使用四条帧带，单帧仍在本素材包留作编辑。
- 边框使用九宫格拉伸，建议边距见 manifest，**不要整图拉伸导致角花变形**。底纹是低对比材质样片，没有保证无缝平铺。
- 节点中心透明，配合已有技能图标叠加；连线端部独立保留，中段伸缩。
- 通用导航的实际显示建议 32–48 CSS px，点击区域至少 44 CSS px。
- 选中微光四帧可低频循环；其余反馈建议单次 320 ms。预览页的重复播放只用于审阅，不能把持续闪烁直接搬进游戏。
- 插值、透明度、触发时机和音效在接入游戏时实现。生成的四帧是动画素材，不能视为已经接入事件的功能。
- 接入入口：`src/ui/InterfaceKit.ts` 与 `src/ui/interface-kit.css`。覆盖菜单、存档、背包、商店、套装详情、技能配置、局内与营地天赋；成功穿戴和修习触发一次反馈。关闭按钮、装备品质框和触屏战斗控件保留各自专用结构。
