# 攻击特效变体

原图 original.png 与生成提示词 prompt.txt 保留。新增三种刀光、三种命中闪光；export.py 使用已获授权的脚本去除烘焙灰色光晕，导出 128×128 透明无损 WebP。白银色素材由游戏按颜色染色。

CombatArt 预加载并缓存六张贴图，每次创建刀光或命中闪光时随机选取，同类连续两次不重复。已有特效数量上限保留，随机播放不增加同时显示的特效数量；资源未就绪使用原贴图。

近战武器动画与刀光共用 MeleeSwing 的角度和挥动进度，刀光朝向跟随此次攻击方向，持续时间跟随攻击动画。剑斜斩交替，斧使用较小斜角，锤偏向竖劈。旋风范围圈仍贴地，不改变技能范围。
