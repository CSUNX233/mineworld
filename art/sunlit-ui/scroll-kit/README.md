# 滑动控件素材

使用内置 image_gen 生成；未使用 CLI/API。原图保留在 Codex generated_images；项目完整图集位于 public/assets/ui/sunlit/scroll-kit/handles.png，通过 CSS 三列定位直接使用，未裁切或重画。

提示词规格：MineWorld Sunlit Quest 明亮冒险像素风；三列等尺寸满幅滑块图集，无间距；金色 #d7a447、青绿 #287f80、银蓝 #93b7c9，统一深蓝 #112238 底色。正面平面视角、细阶梯像素斜边、中央三道横向握持槽、左上象牙色高光、克制的角饰；清晰像素块，禁止文字、景物、透视、模糊和粒子。目标画布 1536×512，实际工具输出 2172×724。

金色用于主层与设置，青绿用于背包/天赋/技能列表，银蓝用于说明/详情。WebKit 滚动条和原生 range 滑块使用图集；Firefox 原生滚动条采用匹配颜色，range 滑块仍使用图集。手机系统可能自动隐藏原生滚动条，保留原生滚动及键盘操作。

引导按纵向滚动、横向滚动、数值拖动分别记录一次。操作成功或点击知道了后写入独立 mineworld_scroll_guidance_v1 偏好，不修改存档。清除网站数据后会重新显示；禁止存储时仅当前页面记忆。
