# P4 像素图标

按现有 Sunlit Quest「②明亮冒险」风格制作，共 6 张图集、30 个独立图标。

- `transparent/sheet-1.png` 至 `sheet-6.png`：最终透明图集，1536 × 1024；三列两行，右下格留空，每张五个图标。
- `icons/`：30 个独立透明 PNG，512 × 512，统一留白。
- `native/`：30 个 128 × 128 原生像素网格版本；512 版本按最近邻整数放大四倍。
- `edge-comparison.png`：边缘优化前后对照，上方为处理前，下方为处理后。
- `preview.png`：六张图集的深蓝底对照预览；深蓝底仅用于预览，不在交付图标中。
- `originals/`：六张内置 image_gen 生成原图，未经覆盖。
- `prompts.json`：完整风格限定、参考图路径和六组生成提示词。
- `manifest.json`：图集、独立图标 ID、原图来源对应关系，顺序为从左到右、从上到下。
- `export.py`：用户授权的本地去棋盘格与分割脚本。
- `export-report.json`：独立素材的透明通道检查记录。

生成方式为内置 image_gen。原始生成结果没有真正透明通道，背景去除重试也仍为 RGB；经用户明确授权，采用本地 Python/Pillow/NumPy 清除棋盘格，并保留图标内部银色材质、高光和透明间隙。最终导出为真实 RGBA PNG。没有使用 API CLI 回退。

本次只制作与分割素材，已接入技能、天赋、召唤指令、专精和战斗状态的图标绑定。

边缘优化：统一像素网格、移除孤立的小碎点、压缩近似颜色（每图最多 40 色，无抖色），透明通道只保留 0/255。采用最近邻保持硬边，没有使用模糊滤镜。六张透明图集与三十张独立素材同步更新，生成原图保留。
