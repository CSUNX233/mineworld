# 攻击按钮图标选型

内置 image_gen 生成，参考 ../icons-atlas.png；三张原图均保留。已选择第 2 款交叉双剑并接入攻击键。

拖动超过 5 CSS 像素切换为 aim-thumb.png 对应的跟手圆点；松手、取消、失去捕获时恢复。仅轻按不隐藏双剑。运行时透明 WebP 位于 public/assets/ui/sunlit/attack。

1. 单剑：简洁清晰。
2. 交叉双剑：对称饱满。
3. 挥砍剑光：更有动作感。
