## 骨架、坐标与挂点

Blender：米制，Z 向上、-Y 向前、+X 是角色自己的左侧。GLB：Y 向上、+Z 向前，+X 仍为角色左侧。此处的左右是解剖左右；正面观看时右手位于画面左边。旧 Player 的部件名称和 X 方向不能作为新骨架的左右依据。

30 根骨骼，其中 root 不变形，29 根可变形；每个顶点最多 2 个有效权重。

| 分组 | 名称 |
| --- | --- |
| 躯干 | root、pelvis、spine、chest、neck、head |
| 双臂 | clavicle.L/R、upper_arm.L/R、forearm.L/R、hand.L/R |
| 手指组 | fingers.L/R、thumb.L/R；不是独立五指精细绑定 |
| 双腿 | thigh.L/R、shin.L/R、foot.L/R、toe.L/R |
| 附件 | cape.upper、cape.lower、tabard、vessel.L |

| 挂点 | 父级 | 用途 |
| --- | --- | --- |
| SF_Grip_R | hand.R | 右手统一握柄，武器资产原点与之重合 |
| SF_AttackAxis_R | hand.R | 基础武器长轴/挥动平面依据；最终武器可有自己的轴偏移 |
| SF_Skill_L | hand.L | 左手技能视觉起点，不能代替逻辑射线与碰撞起点 |
| SF_StaffMuzzle | 法杖对象 | 杖头外端发射点 |
| SF_BladeTip | 剑对象 | 刀尖轨迹检查点 |

Blender 中代理武器局部 +Z 为长度，XZ 为刀刃平面；导出的独立 GLB 武器局部 +Y 为长度，XY 为刀刃平面。GLB 挂点已随导出器转换，后续使用导出节点变换，不把 Blender 的局部轴常量直接照搬到 Three.js。
代理 GLB 的对象名由复制导出带 `.001` 后缀（`SF_StaffMuzzle.001`、`SF_BladeTip.001`）；阶段 C 应以明确映射表记录每个物品 ID 的根节点、握柄偏移、攻击轴与发射节点，不能依赖武器中文名称。

`SF_Head`、`SF_Body` 的 `first_person_visible=false`；`SF_Arm_L/R=true`。这些是后续接入用标记，当前没有替换第一人称代码，也未宣称镜头遮挡已在游戏中验证。

## 检查动作与动画命名

工程内 `QA_StageA_Flex_Only` 是骨架检查用动作：1 帧中立、12 帧接近半幅、24 帧完整弯曲、36 帧回程、48 帧中立。A11 将检查动作烘焙为 48 帧：由脚踝位移反算髋部后移和下降，保持足部原位，躯干前倾、手臂自然平衡，披风恢复垂落、衣摆随大腿抬起。逐帧检查结果见 `squat-qa-check.json`。实际查看过第 6 帧插值及第 24 帧骨架截图。它不作为待机/跳跃/攻击动作导出。
