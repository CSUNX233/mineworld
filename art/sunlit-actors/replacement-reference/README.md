# 星火行者与全敌人参考图

入口：[preview.html](preview.html)。设计说明：[角色替换美术方向](../../../docs/ACTOR_REPLACEMENT_ART_DIRECTION.md)。

本轮只出图，运行中的角色、敌人、Boss 模型与特效均未替换。

## 文件顺序

- 01–02：已选 C 星火行者，基础三视图、武器挂点、第一人称手部和攻击姿态。
- 03–07：五位 Boss 的基础三视图、阶段概念和可活动部件。
- 08–18：十一组敌人模型参考，覆盖注册表全部 35 个非 Boss ID。
- 19：三类现有召唤物的友军变体。
- 20：后续轻斩、重锤、法术打击感的概念分镜。

所有图片使用内置 imagegen 生成，以 01 的色彩、像素密度和几何语言作为风格参考。最终提示词、ID 映射和生成清单保留在 manifest.json。

三视图用于确定体块与附件。不同视图偶有左右手、纹样、比例小差异，正式建模需要统一；参考图上的头身比和英文辅助文字不是运行规格。武器方向与左右手以实际骨骼挂点为准，第一人称示意不能直接裁成游戏手部素材。

将参考板里的像素纹样制作成贴图，避免每个像素块都产生一个网格。Boss 阶段优先使用同一骨架上的甲片、炉门、钟架和核心开合，不同时加载多套完整身体。小怪机制道具保留轮廓差异，普通材质变体共享模型和动画。

## 动作参考追加（21–24）

21：跳跃与落地；22：主角定向受击、防护及空中反馈；23：轻型、重型、盾卫与负重受击；24：四足、软体、悬浮、转台与 Boss 受击。全套共 24 张。

九类模板覆盖全部 40 个敌人，映射见 [hit-template-map.json](hit-template-map.json)，规则见 [动作模板文档](../../../docs/ACTOR_MOTION_TEMPLATES.md)。23–24 中敌人是模板示例，不覆盖 03–18 的已定造型。21 中第一人称贴地手部是重落地姿态示意，普通落地仅用轻微手臂下沉，不强制撑地。全部新增图片由内置 imagegen 生成，最终提示词保留在 manifest.json。
