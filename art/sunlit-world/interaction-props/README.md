# 宝箱、商店与补给货架

依据 `../interaction-props-reference/` 的三张参考板，用 Blender 制作并导出。暖橡木、深蓝布料/铁件、旧金包边、粗像素纹理；简化细小五金与布料褶皱，保留参考图的主体轮廓、分色和结构。

## 源文件与重建

- `interaction-props.blend`：可编辑模型库，包含宝箱闭合与开启展示、商店、货架。
- 建模脚本：仓库根目录下 `scripts/art/build_interaction_props.py`。
- 命令：`D:/34229/blender/blender.exe --background --factory-startup --python scripts/art/build_interaction_props.py`
- 运行时：`public/assets/world/interaction-props/interaction-props.glb`（278848 字节），`pixel-palette.png`（5802 字节，128 × 64）。
- 六个可复用网格，共 3792 三角面；宝箱 976，完整货架 1164，独立补给箱 156，商店 1496。共享材质和几何，货架使用实例化。

## 接入范围

- 所有楼层生成的宝箱，替换原旋转方块。箱体空腔、独立箱盖、后部铰链；0.45 秒缓出掀盖至 105°，空箱留在场景。恢复存档时直接显示已开启状态。
- 所有楼层随机商店，替换前五层旧模型及其余楼层的方块摊位。保留原交互位置和范围。
- 遗迹补给房三格可开启货架，架体与物资各一组实例。开启时按原规则同时清除货架与三格障碍。
- 遗迹中普通装饰补给箱及补给房障碍的补给箱外观统一更新。
- 模型只影响显示，未新增碰撞、未修改奖励与掉落、未更改存档结构或局外天赋。朝向与等比缩放参考真实网格，宝箱额外检查开盖扫过的空间。
- 静态阴影在开盖期间、移除货架时刷新，其余时间继续缓存。
