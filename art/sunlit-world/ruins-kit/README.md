# 石卫遗迹：Blender 模块样板，第 1 轮

目标平台：手机网页横屏。本轮先做荒庭、双径与实际连接通路的建筑／植被样板；共用基础外观应用于 1–5 层。其他房型的专属大型建筑、角色和敌人模型仍待后续验收后制作，不代表六张参考板已经全部还原。

## 可查看的成果

- `preview.html`：参考图与游戏截图、多角度对照。
- `sunlit-ruins-kit.blend`：Blender 5.2 制作的可编辑模型库，各部件分开放置。
- `blender-module-library.png`：Blender 实际渲染的部件总览。
- `material-atlas-source.png`、`paving-source.png`：imagegen 原始材质；未经覆盖的生成原图也保留在 Codex 生成目录。
- `module-budget.json`：逐部件三角面统计。
- `../../../public/assets/world/ruins-kit/` 为运行资源（从仓库根目录实际路径为 `public/assets/world/ruins-kit/`）。

## 已完成及多角度迭代

1. 用 Blender 原生 Python 制作 17 个模块：矮墙、高墙、填缝、立柱、残柱、拱顶、旗帜、藤蔓、灌木、花草、树、苔藓、碎石、火盆、备用地砖、墙挂火把、篝火。
2. 使用新生成的浅暖石灰岩／深蓝织物／橄榄苔藓／旧金属图集，以及带裂纹的石板材质。GLB 不重复打包贴图。
3. 低侧视发现拱顶悬空石块，修正石块咬合；将藤蔓从旗帜正面移到柱侧，保留纹章可读性。
4. 修复墙体真实透光接缝：石块外边界对齐一格，内部灰浆背衬封底，相邻墙间放置凹入填缝。取消高墙与矮墙重复叠放；入口门柱替换同位置的普通柱、旗帜和火盆。
5. 地面少量苔藓、碎石、花草依地图种子分布，靠墙与固定障碍点缀。高度较低，无碰撞；避开门口、出生点、传送门、宝箱和商店附近，保留中心战斗区。
6. 单方向暖阳＋柔化静态建筑阴影，冷暖环境光、ACES 高光压缩。阴影中档 1024、高档 2048；低性能档关闭阴影并减少装饰。高建筑挡住角色时使用局部网点剔除。
7. 墙挂火把与起始／休息房角落篝火随种子固定生成，复用现有像素火焰贴图，带轻微闪动；真实暖光池同时最多 2 盏，低档最多 1 盏，火焰不额外投射阴影。光源根据玩家附近的固定火焰位置分配，远处保留火焰视觉。它们不造成燃烧伤害、治疗或新增交互。
8. 近景检查修正了 Blender 与 glTF 前向相反造成的挂架／火焰错位，并降低篝火近地过曝。`lighting-torch.png` 和 `lighting-camp.png` 为近景截图。当前验收种子有 26 处火焰，其中 1 处篝火，实际只启用 2 个点光源，无点光源阴影贴图。

## 随机逻辑与资源

- 生成器仍先决定网格、房间、遭遇和连接。美术读取结果，不消耗玩法随机数，不改网格或存档结构。
- 拱门只装在实际存在的三格开口，门柱位于两侧墙格。上方结构为非交互装饰，未增加可行走高层。
- 模块共享几何体与材质，按 20 格区域实例化，切层只释放实例缓冲与本层地面，保留已加载模型／材质。
- 模型及图片完成加载后才构建关卡；模型请求有 30 秒超时及最多两次重试；GLTFLoader 单独延迟加载。
- 可破坏补给货架继续由原来的渲染和交互系统管理。

## 与参考图仍有差距

本轮确立了材质、建筑高度、拱门与植被方向。参考图的雕刻、复杂残损、藤蔓自然形态、远景地形和角色精度仍明显更丰富；当前外围仍是平面底地。通路仍遵循现有三格可行走宽度，宽阔感主要来自房间中心净空与高低层次，并未偷偷改变战斗面积。下一轮应在本样板验收后逐项提升，而非宣称已经完全复刻参考图。

## 重建

在仓库根目录运行：

```powershell
& 'D:/34229/blender/blender.exe' --background --factory-startup --python scripts/art/build_ruins_kit.py
```

脚本先导出原点对齐的游戏模块，再排列模型库、保存 `.blend`、渲染部件图。游戏使用导出的 GLB，而不是模型库展示位置。
