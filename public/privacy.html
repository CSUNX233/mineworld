桑尼工作室（以下简称“我们”）重视您的个人信息和隐私。本政策说明《深渊，请等一下》当前 Android 版本及网页版本处理信息的方式，以及您管理这些信息的途径。

请先了解：当前游戏无注册账号、无内购、无广告，也未接入第三方统计、广告、实名认证或防沉迷 SDK。冒险存档、营地研究和设置保存在本机，不自动上传给我们。本政策及隐私同意提示不代表已完成实名认证或防沉迷认证。未来新增相关服务时，我们会先更新说明，并按要求完成告知及授权。

一、我们处理哪些信息、用于什么目的

  • 本地游戏数据：包括存档名称、本地生成的存档标识、关卡进度、角色属性、装备、材料、天赋与研究、通关记录及新手引导状态，用于恢复冒险和保留成长；音量、操作灵敏度、显示与输入设置用于保存您的偏好。这些标识仅用于区分本地游戏记录，不是设备唯一标识或注册账号。
  • 隐私选择：本机保存您同意的政策版本，用于避免重复提示。拒绝时不会初始化游戏主逻辑；网页展示自身仍需加载页面文件。
  • 设备适配：程序在本机读取浏览器提供的浏览器标识（User-Agent）、触屏支持、窗口及屏幕尺寸、像素比例、逻辑处理器数量等运行环境信息，用于触屏布局与性能档位适配，不用于广告画像，不自动上传给我们。不读取 IMEI、IMSI、Android ID、OAID、MAC 地址或已安装应用列表。
  • 本地运行记录：游戏会在当前会话内存中保存有限的战斗、经济和运行事件以辅助故障排查，不自动上传，关闭页面或结束应用进程后不再保留该会话记录。您主动导出的诊断文件或旧存档会保存在您选择的本地位置；仅当您自行发送给我们时，我们才会收到。
  • 网页访问：网页版本及在线隐私页通过托管服务提供文件。访问时，托管服务商会接收到提供页面所必需的 IP 地址、请求时间、请求路径和浏览器请求头等连接信息，用于内容传输和服务安全。当前网站使用 Cloudflare / Vercel 部署，具体由您访问的网址决定。Android 安装包的游戏资源与本政策随包提供，游戏内容不依赖从这些网站下载。
  • 您主动联系我们：我们会收到您提供的邮箱地址、邮件内容及主动附带的截图或文件，仅用于答复咨询、处理投诉、定位故障和办理信息权利请求。请避免发送身份证照片、密码及与问题无关的个人信息。

二、设备权限和第三方组件

Android 包声明网络权限（INTERNET），用于 WebView 网络访问能力。这是系统普通权限，不会出现运行时授权弹窗；声明权限本身不表示上传存档。当前游戏不申请通讯录、定位、摄像头、麦克风、电话或广泛读取手机文件的权限。导出操作由系统或浏览器提供文件保存能力。

  • Capacitor Core / Android / App（Ionic）：用于将网页游戏运行在 Android 中、提供返回键、应用状态和退出能力。当前接入代码不通过这些组件上传玩家资料或采集广告标识。组件说明。
  • Android System WebView：系统提供的网页运行环境，用于显示界面、执行游戏逻辑和本地存储。其版本更新、系统诊断或系统备份由设备系统及您选择的设置管理，不由游戏配置上传。
  • Three.js：本地三维渲染库，用于显示地图、角色和特效，当前接入不包含统计上传服务。组件说明。
  • 网页托管：Cloudflare 隐私政策；Vercel 隐私政策。仅访问对应在线服务时产生必要连接信息；游戏未接入其访客行为分析 SDK。

当前没有广告或支付 SDK。将来接入广告、登录、实名认证或其他会处理个人信息的服务时，我们会在启用前列明服务商、信息种类、目的、权限及相应权利路径，并依法取得必要授权，不以当前同意代替未来新增用途的授权。

三、信息保存、共享及安全

存档和设置使用本机浏览器 / WebView 的 localStorage 保存，直到您删除相应数据、清除应用数据或由系统清理。游戏自身不提供云存档同步。Android 系统备份可能依设备设置备份应用数据；其存储和恢复由设备系统控制，请同时检查系统备份设置。您导出的文件由您自行保管。

我们未主动设置广告追踪 Cookie；本地存储用于上述游戏功能，不用于跨网站追踪。浏览器缓存用于资源加载；在线托管服务可能为安全验证使用其必要技术，详见对应服务说明。

我们不出售、出租或公开玩家存档，不主动将本地存档传送至境外。网页托管服务可能由境外或全球节点处理连接信息，不能将网页访问等同于所有信息仅在境内存储。您通过邮件提交的信息通过电子邮件服务传递，我们仅在处理请求所必要的期限内保留，处理完成后删除不再需要的信息；法律要求保存的除外。

除履行法定义务、处理您提出的请求所必需或另行取得有效授权外，我们不向第三方提供您主动提交的个人信息。涉及运营主体变更及信息转移时，我们将依法告知接收方与联系方式，并要求其继续履行保护义务。

我们通过限制应用权限、不自动上传存档、使用 HTTPS 提供在线页面等方式减少风险，并限制对联系邮件的访问。请保管好设备与导出文件。本地存储不等同于加密保险箱，清除数据前请确认是否需要保留进度。发生个人信息安全事件时，我们将依法采取补救、通知和报告措施。

四、您如何管理信息

  • 查看与修改：通过存档界面、角色界面、营地天赋及设置界面查看和管理相应游戏数据。对您通过邮件提供的信息，可联系我们申请查阅、复制、更正或删除。
  • 删除存档：在存档选择界面删除指定存档。营地研究是跨存档共享的，删除单个存档不会删除共享营地数据。
  • 删除全部本地数据：Android 可在系统“设置 → 应用 → 深渊，请等一下 → 存储”中清除应用数据；网页可在浏览器网站设置中清除该游戏网站的数据。此操作会同时删除存档、共享营地、设置和隐私选择，无法由我们恢复。系统备份和已经导出的文件需另行删除。
  • 撤回同意：可从主菜单的“隐私政策”入口选择撤回同意并返回隐私提示；撤回不删除现有存档，也不影响撤回前依法进行的处理。也可停止使用、清除应用数据，或通过邮箱联系我们。
  • 账号注销：当前无注册账号，无需注销网络账号；停止使用及按上述方式删除本地数据即可。若您曾提交客服资料，可另外申请删除。

对于合理请求，我们将及时核实并处理。为保护您的信息，我们仅核验与请求相关的必要信息，不要求提供与问题无关的身份证件。如因法律义务等原因无法满足请求，我们会说明理由。您也可依法向有关监管部门投诉或寻求其他救济。

五、未成年人保护

未成年人应在监护人的指导下阅读本政策并使用游戏；不满十四周岁儿童向我们提供个人信息前，应取得监护人的同意。监护人可通过下方邮箱申请查看、更正或删除其监护对象主动提交的信息。如发现未经有效监护人同意收到了儿童个人信息，我们会核实并采取删除等措施。本政策不能代替平台要求的真实身份核验、游戏时长限制及其他未成年人保护措施。

六、政策更新

我们会在本页标明更新日期。新增个人信息处理目的、种类、接收方等重大变化时，会通过游戏内显著提示告知，并在依法需要时重新征得同意。政策文本版本随游戏版本保留；您可通过邮箱申请查询与已使用版本相关的政策。
