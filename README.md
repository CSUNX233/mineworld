# MineWorld / 方块割草：深渊

Three.js + TypeScript + Vite 的 Minecraft 风格方块动作游戏，支持第一/第三人称与触屏操作，覆盖房间探索、方向战斗、局内天赋构筑、随机装备、楼层推进与存档。

## 运行

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5173/`，点击“开始游戏”进入五槽存档界面，再进入该存档的营地。营地可选择起始流派、解锁新方向或继续当前局；删除存档需要确认。生产构建：

```bash
npm run build
npm run preview
```

## 操作

- WASD：移动
- 鼠标：旋转视角（点击画面锁定鼠标）
- Shift：冲刺
- 空格：跳跃
- 鼠标左键：向当前视角前方释放近战攻击（前方扇形范围，不自动锁定）
- 数字键 1/2/3：前方旋风斩 / 冲刺斩 / 火球术，分别有独立范围和粒子特效
- E：交互（开宝箱、圣所恢复、进入地图商店或已激活传送门）；移动端点击靠近时出现的交互按钮
- Tab 或 B：打开/关闭背包
- C：切换第一人称/第三人称
- R：第三人称镜头回到角色朝向（转动鼠标可立即取消回正）
- 鼠标滚轮：调整第三人称镜头距离；按住右键：保持面向镜头前方横移
- Esc：游戏暂停（可继续或返回主菜单；背包打开时 Esc 关闭背包）
- P：打开局内天赋面板，安全房可改点，战斗中可查看
- 数字键 4：引爆（需点亮吞噬之火并装备技能）；冰霜/闪电旧树入口暂不开放

第三人称使用直接响应的旋转镜头，默认提高俯视角并将角色放在画面偏下方。攻击方向标记显示角色前方的攻击距离参考点，遇到墙壁会变为橙色；第三人称的普攻和方向技能沿水平视角方向释放。贴墙时镜头立即收近，离开障碍后平滑恢复；距离太近时隐藏角色模型以避免挡住画面。暂停菜单可调整灵敏度，以及是否在开始前进时自动回正。

第一人称法杖和火球沿准星方向发射，支持上下瞄准；投射物沿飞行路径检测墙壁、地面和怪物。手持武器按屏幕比例缩放，贴墙仍可见。

移动端摇杆支持 360° 连续方向与轻推慢走，拖到外侧冲刺；另一根手指可以同时转镜头或攻击。提供独立跳跃按钮，靠近宝箱或激活的传送门时出现交互按钮。四个技能位置显示名称和剩余冷却，空位可直接打开技能配置。

手机横屏背包为装备/物品左右分区，竖屏通过页签切换。点击物品打开详情和装备对比，再选择穿戴、卸下或打造；系统返回键优先关闭当前详情或面板。背包提供一键整理，以及按品质及以下批量分解（确认前显示数量和材料）。整理按品质、部位、物品等级排序。装备出售仅在地图商店进行，支持单件和按品质批量出售。音量与静音在暂停菜单中调整。

## 已实现系统

- 带种子的 40×40 地牢，每层 9 个功能房间，环路连接与房间障碍模板；后期不再扩大地图
- 体素方块渲染、玩家 AABB 碰撞与重力、平滑跟随相机
- 近战/远程/冲锋/Boss 怪物，简单追击 AI 与远程弹幕
- 伤害、暴击、连杀、击退/震屏、hitstop、粒子与程序化 Web Audio 音效
- 金币、血瓶、法力瓶和带随机词条的装备掉落
- 品质词条、装备槽位、背包比较/穿戴/整理/分解
- 一局 25 层，每 5 层一次 Boss 战；第 5/10/15/20 层完成主线后可低收益提前结算或继续，第 25 层通关，死亡结束本局；精英、宝藏和恢复房可选
- 进入战斗房生成遭遇并封闭出入口，清完敌人后解锁；屏障接入移动、冲刺、投射物和寻路
- P2 火系局内树：蔓延与主动引爆互斥，最多 10 点来自等级和 Boss 主线里程碑；前两次安全房重置免费，之后花金币
- 精英房奖励稀有装备，宝藏提供重铸材料，恢复房每层使用一次
- 地图商店随机出现，每三层至少一个，小地图标为“商”；传送门负责换层，Boss 阶段可提前结算
- 商店有四件有限商品、递增价格换货（每层三次）、按部位随机委托（三次）、恢复补给（两次）和装备/材料出售；库存及次数随存档保存
- localStorage 五槽存档，每槽独立局外档案与单局；营地解锁起始流派，结算保存研究经验与局外天赋点
- 移动端适配可直接游玩，横屏竖屏均可

## 目录

```
src/
  core/        Game、Input、EventBus、Save、Audio、Effects
  combat/      投射物运动与碰撞查询
  world/       FloorGenerator、BlockRegistry、World、Textures
  player/      Player、PlayerController、CombatSystem
  monsters/    Monster、MonsterAI、MonsterSpawner
  items/       ItemGenerator、AffixSystem、LootSystem、Inventory、EquipmentManager
  ui/          HUD、InventoryUI、ItemTooltip、DamageNumber、Minimap
  data/        monsters/items/affixes/floors 配置与平衡公式
  utils/       RNG、seededRandom、math
```

模块职责、扩展方式和后续推进顺序见 [架构说明](docs/ARCHITECTURE.md)。

完整玩法目标、局外/局内成长规则、存档方案、开发顺序与验收标准见 [玩法重构开发文档](docs/DEVELOPMENT_PLAN.md)，各项实现状态以阶段交付说明为准。

当前验收入口见 [P2 火系构筑与战斗房屏障](docs/P2_DELIVERY.md)，基础单局规则见 [P1 交付说明](docs/P1_DELIVERY.md)。其他流派新树、更多技能、随机地图结构与正式美术按后续阶段推进。

P0 试玩记录与现状审计见 [基线与手动验收](docs/P0_BASELINE.md)。暂停菜单可导出当前试玩记录；新开游戏可使用 `?seed=42` 固定地图种子。记录仅保留在当前页面内存，刷新或开始另一段试玩会清空，不上传，也不影响游戏存档。

运行 `npm test` 验证地图连通性、房间流程、专精、缓存和存档迁移；`npm run build` 检查类型与生产构建。

存档外层为版本 3，分开保存局外档案、当前局与待展示结算。旧 v1/v2 存档经确认后先备份，再保留为可导出的纪念记录；新单局不继承旧角色装备和金币。

## 素材说明

纹理当前使用 Canvas 程序化生成的 16x16 像素贴图，因此不依赖外部文件即可运行。若需要接入仓库贴图，可将 PNG 放入 `public/textures/` 并在 `src/world/Textures.ts` 中改为 `TextureLoader` 加载，同时保留 Canvas 后备。
