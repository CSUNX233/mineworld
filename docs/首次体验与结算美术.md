# 首次体验与结算美术

- 新玩家首次完成地牢加载后暂停，选择第一或第三人称。说明视角按钮可随时切换。选择结果作为新局默认视角，读取旧局时仍尊重该局保存的视角。
- 首次死亡显示「来自作者的善意ovo」。点击后恢复生命、法力、护盾，清除异常状态，提供 3 秒无敌，继续当前房间，不结算、不清空装备或进度。以后死亡按原流程结算。
- 首次体验记录使用独立的 `mineworld_new_player_v1` 浏览器存储项，对五个存档共用。已有存档的老玩家不重新触发新手奖励。不更改原有存档格式或共享营地数据。清除浏览器全部站点数据仍会重置本地身份；当前无账号同步。
- 免费复活弹窗待确认期间不将死亡快照覆盖到存档；接受复活后保存活着的角色状态。保存失败沿用游戏重试流程。
- 死亡标题「你坠入了无尽的深渊....」，通关标题「恭喜你活下来了...暂时。」。显示结算记录中的真实研究经验和转化天赋点，保留未保存提示与重试按钮，避免重复发奖。
- 死亡和通关页底部显示「看在作者这么可爱的份上，给个好评呗」。仅文案，不接外部评分跳转。
