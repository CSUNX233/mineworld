# 像素美术风格提案（已选②明亮冒险）

用户已选定②明亮冒险 / Sunlit Quest。下文保留五张概念图的原始方向记录。后续用户明确要求提前生成整套 UI 并接入游戏，素材与接入说明见 [SUNLIT_UI_ASSETS.md](SUNLIT_UI_ASSETS.md)。

实施顺序：**当前提前统一 UI；角色、敌人和场景继续使用 3D 粗模完成玩法。** 全部玩法功能完成后再实施 HD-2D：保留 3D 场景和逻辑，将角色、敌人、召唤物表现替换为多方向像素动画面片。详细边界和 P9/P10 顺序见 [开发文档第 6.8 节](DEVELOPMENT_PLAN.md#68-美术制作顺序粗模先行风格统一后替换)。

## 全部提案的严格限定

- 清晰方形像素与统一像素密度，轮廓和材质由像素块组织；禁止抗锯齿、平滑渐变、写实 PBR、绘画笔触、景深和模糊泛光。
- 每种材质使用 3–4 档离散明暗；受限色板，技能亮光由分阶像素表现。
- 场景、角色、怪物、装备、特效、字体、边框与图标必须属于同一套视觉语言。
- 五张保持可比内容：第三人称斜俯视遗迹战斗场景、持杖角色、盾卫、支援怪、小型召唤物、火焰、掉落物，以及同风格背包与技能栏。
- HUD 包含生命、法力、经验、小地图；护盾是血条左侧覆盖 40% 的银色层，无护盾数字。
- 概念图展示审美方向，不代表已经实现的游戏画面。生成图的色板及像素网格属于提示约束，正式素材仍需制作规范与验收。

## 五个候选方向

1. **暗黑哥特 / Gothic Embers**：炭黑、灰紫、骨白、旧金、余烬橙；约 28 色，中细像素，修长轮廓，铁与黄铜 UI，压抑但可读。
2. **明亮冒险 / Sunlit Quest**：靛蓝轮廓、青绿、叶绿、暖奶油、陶土、珊瑚橙；约 32 色，粗像素块与紧凑角色，明亮遗迹，清晰厚边框。
3. **冷色奥术 / Astral Relics**：深蓝、群青、灰紫、青光、银白，少量火焰珊瑚色；约 24 色，细致克制，几何符文与双线银框，不引入科幻电子设备。
4. **荒野遗迹 / Wildbound Ruins**：森林绿、苔橄榄、赭石、陶红、旧米白；约 24 色，粗砺像素肌理，石木皮革与青铜，少量规则抖色。
5. **复古掌机 / Pocket Legends**：约 12 色，明显大像素、低分辨率整数放大观感，2–3 档明暗，统一描边，极简双线边框与符号化图标。

选定后锁定主色板、像素尺度、模型比例、贴图采样、轮廓与阴影、特效表现、字体与 UI 状态规范，再生成正式素材。
