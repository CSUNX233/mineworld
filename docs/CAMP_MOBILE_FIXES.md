# 共享营地与移动端修复

- 同一浏览器、同一站点的五个冒险存档共用营地天赋点、解锁、图鉴和专精。局内装备、等级与天赋继续独立。
- 首次读取合并旧档：独立档案的未花费点数与研究经验汇总，相同 profileId 的复制档按最高余额去重；解锁取并集。旧槽位原始数据保留，直到用户主动删除该槽位。
- 共享成长与冒险结算通过单个 localStorage 写入一起保存，失败不部分扣点。旧页面写入时检查共享版本，防止覆盖其他页面的成长。
- 删除冒险存档保留共享营地，并更新营地和删除说明。
- 手机第一人称视角按钮去除附加描边；原有六个技能图标从旧图集中单独导出透明素材，保留原图集。
- 后台暂停并停止渲染，返回重置帧计时和画布大小；处理 WebGL 上下文丢失、恢复，避免继续使用失效图形状态。偶发后台白屏尚需原手机复现验收。
- 召唤来源复核：洗点、读档、战斗更新清理失去天赋来源的编队，卸下疫毒六件套后清理装备来源骷髅。疫毒六件套无需召唤天赋即可击杀召唤属于既有装备能力；召唤流开局自动点亮根节点也属正常行为。

验证范围：共享迁移、扣点/保存失败、复制档去重、召唤来源清理的基本逻辑检查与编译。未进行批量数值模拟或全机型测试。
