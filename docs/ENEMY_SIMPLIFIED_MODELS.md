# 全敌人简化模型接入

本轮将现有 35 种小怪、5 个 Boss 统一改为程序拼接的低多边形模型，沿用各章节配色与角色设计的识别物。主角星火行者模型和动作不在本轮替换范围。

- `src/monsters/EnemyAppearance.ts`：40 个明确的外观配置，共用士兵、施法者、盾卫、重装、兽类、软体、浮游和机械底型。通过面罩、披布、武器、背负物、晶体与机械配件区分。
- Boss：断誓旗盾、双烟囱炉心、巨钟冠与吊钟、晶角披翼、堡垒肩甲。断誓门卫的盾与剑、执政官的炉心、返刃守墓人的刀环保留独立部件，继续接受现有控制器的状态驱动。
- 新贴图：`public/assets/actors/enemies/material-atlas.png`，四区分别为布、金属、石骨、鳞皮。内置 imagegen 生成，提示词保存在 `art/sunlit-actors/enemy-kit/prompt.txt`。顶点色着色、每区 32×32 采样、最近邻过滤，接入原有加载屏贴图就绪检查。
- 主体静态部件合并为一个 Mesh；同种怪物共享缓存几何体，使用独立材质控制闪白和隐身。通常主体一次绘制，少数独立机制部件额外绘制；不计血条、阴影和机制提示。主体约 76–890 三角面。
- 命中时全模型（含独立武器）纯白闪烁约 90 毫秒，无新增受击姿势。保留移动起伏、攻击预备动作、死亡收缩、燃烧粒子及现有击退判定。隐身保留透明度，不会被闪白覆盖成不透明。
- 取消普通挥刀、余烬刃和旋风斩中的刀光贴片；旋风斩的范围波纹、命中反馈、音效及主角挥刀动作继续保留。
- 清除旧 Monster 拼块入口、后期敌人 GLB 外观入口及重复的控制器持有物。后期折面术士的镜像也使用新模型。场景 GLB 中的历史敌人源网格未重导出，运行时不再创建其外观实例。

本轮不更改敌人的数值、AI、碰撞体、掉落、存档结构或 Boss 战斗规则；旧存档按原敌人 ID 自动使用新外观。模型几何由外观库缓存持有，个体移除只释放自己的材质，不释放其他同种怪物还在使用的几何。

## 基础验证

- TypeScript 与生产构建通过。
- 浏览器逐个创建全部 40 种敌人；检查伤害扣血、闪白开始与结束、材质隔离、共享几何、隐身恢复、Boss 特殊部件与回旋刃引用。
- 进入实际第一层战斗房：成功生成 4 个敌人，普通攻击造成伤害并触发闪白，主角新模型正常加载。
- 已查看正面/斜视、背面、闪白和横屏游戏截图。浏览器使用手机横屏模拟，未代替真机性能验收。
