# 试玩反馈调整：全层强度、第五层节奏与掉落

本轮依据用户最新要求，在已有五档章节压力之上，1–25 层普通怪与 Boss 的生命、攻击各乘 1.20。两项独立增加 20%，合起来的生命×攻击代理增幅为 44%；不是额外只加 20% 综合压力，也不代表死亡率的测量变化。

旧存档怪物按保存时的全局倍率换算生命，保留当前生命比例。新存档记录 `difficultyStatMultiplier`，反复读档不会再次变强或回满。实际整数生命与攻击仍按既有规则取整。

## 怪物掉落

- 普通怪装备概率由 `25% + 楼层×1%` 改为 `32% + 楼层×1.2%`，上限 65%。实际第 1–25 层为 33.2%–62%。弱召唤增援/送葬者原有收益折算继续保留。
- 仅怪物掉落的黄、橙、红品质权重分别乘 1.5、1.7、1.8；这是权重变化，不是直接加概率点。幸运继续使用原来的有限递减加成。
- Boss 必掉两件黄装以上；第十层及之后，第二件保底橙装以上，仍有机会是红装，不保证红装。
- 商店、宝箱与打造的品质表不变；金币、药水和材料的原有概率不因装备调整额外提高。

类型与生产构建通过。基础检查覆盖章节倍率、旧怪生命迁移不重复、第六层实际数量、Boss 保底品质、第五层出手节奏，以及此前屏障入口回归。未执行百局模拟或真实设备压力测试。
