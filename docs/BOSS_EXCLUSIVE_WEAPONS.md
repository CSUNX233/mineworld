# 五位领主的专属红武

每把为 mythic 红装、独立一件套，只占武器槽。其余八个部位可混搭现有套装；不计入死亡收割的九件身份。两把法杖沿用现有远程普攻，其余三把沿用近战。

| Boss | 武器 | 单件玩法 |
|---|---|---|
| 断誓门卫 | 断誓·门扉大剑 | 三次直接命中触发破誓重击、减速与护盾 |
| 铸炉执政官 | 赤炉·执政战锤 | 耗蓝施法蓄炉压，下一次命中产生火焰范围爆震 |
| 末代司钟人 | 回葬·司钟法杖 | 命中后延迟回响并减速，目标死亡不转移 |
| 深渊领主 | 深瞳·领主法杖 | 命中后连续三次暗影追击，原目标死亡可转向同房间近敌 |
| 遗迹监守者 | 封界·监守长钺 | 战斗移动积累镇印，命中释放范围镇压与减速 |

## 掉落

每次 Boss 击杀只进行一次共享红装判定，基础 3%；保留既有楼层衰减，1–5 层 2.1%、6–10 层 2.4%、11–15 层 2.7%、16 层起 3%。幸运不增加该专属概率。

命中后：50% 该 Boss 专武，50% 原有死亡收割遗物池。因此专武的每次击杀实际概率依次为 1.05%、1.2%、1.35%、1.5%。同一次判定不会同时给出两件。普通怪、商店、宝箱和常规生成池不会生成专武。旧存档中的同名 Boss 仍按实际身份掉落。

## 运行与存档

能力均有 3 秒冷却；直接命中计数每 0.25 秒至多一次；追加伤害通过现有护甲、元素抗性、Boss 阶段减伤与死亡结算入口，禁止触发装备连锁。范围攻击最多三目标；连射队列最多三个条目。

换武器不重置剩余冷却。切层、离战、卸下时清除待结算目标及蓄力；保存剩余冷却，读档不会释放旧目标上的隐形回响。旧存档缺少新字段时使用默认值，无版本迁移或旧余额改写。

首次拾取沿用共享营地图鉴，总数由 9 增至 14。删除单个冒险存档、死亡不会清除已有图鉴和局外成长。定向重铸只改普通词条，保留专武身份及能力。

## 美术与验证

五张透明 PNG 使用内置 imagegen 分别生成；提示词和资源位置见 `art/sunlit-ui/boss-weapons/README.md`。共用物品图片解析入口，因此背包、装备槽、详情、图鉴和地面掉落均显示对应图标，并继承现有 mythic 炫彩边框与掉落光柱。

构建通过，专武、掉落概率、重铸、存档及结算相关 13 项测试通过。浏览器用独立临时装备数据检查了 1280×800 电脑和 844×390 手机横屏背包，五张图标成功加载且宽高相等；没有改动玩家正式存档。未进行完整通关或长时间平衡测试。
