# 16–25 层首轮实现与验收

2026-09-13。本轮包含场景、新怪物、机关玩法与低平台，不包含发布推送。

查看 [参考图 / 实际游戏 / Blender 模型对照页](../art/sunlit-world/chapters-16-25-kit/preview.html)。原设计是方向与目标，本页记录当前实际行为及取舍。

## 已接入内容

- **蚀光深庭（16–20）**：紫灰晶岩、琥珀灯、观测环和三瞳地标。显影灯揭露猎手；镜座控制术士残像；眼核可以被玩家近身攻击、交互或敌方锁向凝视击碎。保留纯清扫房、物资房、可选试炼及第 20 层深渊领主。
- **封界天垒（21–25）**：浅石城墙、青铁镇印、赭金旗、暖太阳与冷天空补光。击败持旗军士后夺旗；导流座改变镇压波方向并伤敌；关闭封印停止有限增援。第 25 层保留遗迹监守者身份与掉落关系。
- 两章各七种房间模板、六种新敌人。三种有回路/近路差异的拓扑，房间由不规则格子掩码生成。普通层七房、试炼层八房、Boss 层五房。
- 宽通路、门洞、墙柱、残损、晶簇/草丛、远景塔、每房灯池。原宝箱/商店模型复用，并增加两章配色。试炼在中央守卫雕像处交互。
- 折镜庭、悬瞳庭、镇印堤、封印庭使用 0.8 米低平台，八级、宽约 2.8 米的台阶连接；两座 Boss 房设置侧台。玩家、怪物和召唤物使用同一地面高度函数。第一版没有电梯、悬空必跳路线或上下重叠的可行走楼层。

## 当前战斗规则

| 对象 | 实际行为 |
| --- | --- |
| 薄影猎手 | 最多潜行三秒，接近时更明显，地面留下淡色标记；受伤或进入显影灯域现身；现身后有攻击预警。依然可以被伤害和计入清场。 |
| 折面术士 | 镜座存在时施法产生两个无碰撞、无收益残像；摧毁镜座阻止后续残像。 |
| 瞳灯看守 | 凝视先跟随，再锁向约 0.8 秒；可以引导其击碎眼核。 |
| 缝隙织者 / 镇印执械 | 地面线状威胁；跳起超过当前地面 0.42 米可躲，也可以侧移。 |
| 持旗军士 / 军旗 | 军士存活且军旗未夺时，同房攻势提高 10%；军士死后可夺旗，制造短输出窗口。 |
| 缄印司录 / 封印 | 每座封印最多四个援军；关闭后不会继续生成。援军为同层基础兵的 55% 生命，无额外经验/掉落。 |
| 索敌弩手 | 窄线锁向攻击；晶背负卫和连盾卫正面受伤降低 20%，绕侧可避开。 |
| 深渊领主 | 三个生命阶段，锁线、落点、连续冲撞、有限召唤；冲撞约 0.55 秒最多行进八米，受房间与墙碰撞约束，单次只命中一次。 |
| 遗迹监守者 | 地面波、落点、封印增援，保留常态 0.8 倍受伤及暴露时 1.5 倍受伤。 |

同房主要空间招式排队，施法死亡/离开有效战斗房时清理预警。六类设施不额外产出击杀奖励；显影灯两次、每次八秒；导流座最多成功导流两次。可选试炼追加一次四兵第二波，标记随存档保存。

## 存档与实现边界

新地图内容使用版本 7。旧存档当前层沿原版本恢复，正常进入下一层时生成新版本；没有重建账号档案、共享局外天赋或研究经验。设施使用次数、方向、增援余量、试炼第二波标记保存；读取时取消半截施法，重新给予安全冷却。

没有改变研究经验、套装或红装掉落公式。新敌人的常规遭遇采用已有楼层数值倍率；有限援军不额外扩大经济产出。两章的新敌群尚未做百局标定，不能声称流派差异已达到 10% 或真人通过率符合目标。

首轮实现和完整设计的差异：

- 电梯仅是候选，当前选择连续宽楼梯，避免引入移动平台与多层寻路风险。
- 近身攻击与通用交互均能处理镜座/眼核；尚未让所有远程技能投射物独立命中设施。
- 镇压波先预警后结算直线区域，没有制作长距离逐段推进的波面动画；导流方向影响敌方命中区域。
- 阵型协作目前为军旗攻势支援、正面防护及招式排队，没有完整盾墙编队寻路。
- 宽房间与回路已实现，但尚未对照前章完成 ±10% 总可走面积/主路长度预算测量。
- AI 概念图不等于施工图。实际模型保留主要轮廓和配色，细部密度、敌人独立动作与宏大远景仍较简化。剖视截图为了显示内部隐藏了前景墙，不改变游戏碰撞。

## 资产与复用

- `scripts/art/build_late_chapter_kits.py`：Blender 建模、图集、GLB、模块正/侧/顶视图及预算导出。
- `public/assets/world/abyss-kit/`、`citadel-kit/`：每章一个 GLB、一个 512 像素共享图集；静态模块按区块实例化，地面按区块合并。
- `art/sunlit-world/chapters-16-25-reference/`：十二张场景/模块/材质参考，加两张敌人参考，保留全部提示词。
- `art/sunlit-world/chapters-16-25-kit/`：两份 Blender 模型库、十层斜俯视、十四种房间三视图、两章连接处三视图、手机两种视角截图。
- `scripts/art/capture_late_*.playwright.js`：通过 Playwright CLI 对本地游戏截图。需要已启动 Vite 和浏览器；移动截图使用 Android UA、触摸和横屏设备模拟，不是实体手机跑分。
