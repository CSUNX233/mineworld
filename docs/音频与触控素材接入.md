# 选定音频与触控素材接入（2026-09-13）

本轮接入用户确认的 96 项录音素材：8 首音乐与 88 项音效/环境声。移除旧 AudioManager 的振荡器、程序噪声和旧音频文件。源素材与无损响度版本保留在桌面的“音效与音乐”，发布资源位于 `public/audio/selected-v1`，合计约 18.36 MiB；不一次下载、解码整个素材库。

## 音乐分配

| 场景 | 音乐 |
| --- | --- |
| 1–5 | Town in ruins loop |
| 6–10 | Searching |
| 11–15 | Into the Ruined Temple |
| 16–20 | Loopable Dungeon Ambience |
| 21–25 | Ominous（用户二次确认） |

音乐以约 -26 LUFS 的录音版本为基础，Heavy Dungeon 相比原始文件降低 14.1 dB。各章配置最多两层环境声；音乐同曲不因进房重启，切换淡出入，最多两路音乐流。普通战斗继续使用所在章节音乐，本轮没有擅自添加用户未选定的战斗曲。音乐使用浏览器媒体流播放真实录音，通过 Web Audio 混音；不再生成合成音效。媒体循环开启，但长曲的音乐性无缝接缝仍需用户试听验收。

## 声音事件与预算

`AudioAssets.ts` 管文件映射，`AudioEvents.ts` 管用途、变体、间隔和优先级，`AudioManager.ts` 管播放、混音与生命周期。Game 仅在原有事件成功后触发声音，不改战斗伤害、掉率、经验、存档或输入规则。

- 技能按火、冰、雷、灵魂、地裂和物理动作分组，群体命中按音色限频；删除原有技能的重复通用释放声。
- 怪物按黏液、亡灵、深渊、兽类复用声线，攻击、死亡、低密度呼吸和 Boss 生命阶段提示分别触发。距离超过 20 格不播放短音效，其余衰减并做左右声像。
- 护盾从正值降到零触发玻璃破裂；闪避不触发受伤音。主角受伤暂用用户已有的血肉冲击录音，不冒充已选定的专属人声。
- 同一时刻最多 18 个短音效；每类 1–3 个并发、65–1800 ms 间隔。满额时重要声音替换低优先级声音；护盾破裂、玩家受伤、红装掉落优先。
- 一批装备掉落在 60 ms 内合并，只突出最高品质。红装和护盾破裂将背景音乐短暂压低约 5 dB。
- 穿卸、锻造、药剂、材料、金币、宝箱、传送、圣所、屏障、UI 点击/返回/错误接入录音。暂停时允许背包和商店操作声，停止战斗和脚步声。
- 录音解码并发最多 3，解码缓存最多 24 MiB，按访问顺序淘汰。过时命中不会在下载完成后补播；无网络时不退回合成声音。
- 音乐流不进入完整解码缓存。后台暂停、回前台/用户手势恢复；音量设置独立保存在 `mineworld-audio-v1`，不修改游戏存档结构。

作者、来源、许可及处理说明见 `public/audio/selected-v1/CREDITS.md`。用户原有录音沿用原文件来源记录。

## 摇杆素材

内置 image_gen 生成双格透明图集，转为保留透明通道的 WebP：`public/assets/ui/sunlit/controls/joystick-sheet.webp`。CSS 直接定位图集两格，不额外画替代品。左格用于移动摇杆、技能和普攻底座；右格用于移动圆钮和施法/攻击拖动圆钮。原有双击跳跃、浮动摇杆、多指输入、取消施法判定保持不变。

生成提示词：

> Generate one production game UI sprite sheet: two isolated circular sprites side by side in equal square cells, transparent background with real alpha, no labels no text no mockup. LEFT sprite: mobile virtual joystick BASE, thin elegant antique gold / ivory pixel-art circular rim, dark desaturated petrol blue recessed translucent center, four tiny cardinal notch accents, absolutely front-on perfect circle, restrained detail to stay clear at 90px. RIGHT sprite: separate joystick movable THUMB circular medallion, matching ivory bevel and antique gold trim, desaturated teal center with small simple diamond highlight. Match indie dark-fantasy sunlit pixel UI with crisp chunky pixels, limited palette #d7a447 #fff0cb #1c304a, pixel-art stair-step edges, no smooth photoreal shading. Base must also serve as skill and attack button background behind existing icons; no swords or glyphs in base center. Both centered within their cells, outer visible circle fills 90 percent of square cell; no drop shadow outside silhouette, no checkerboard baked in. Output 1024x512 landscape sprite sheet.

工具实际输出 1774×887，保持原比例接入。

## 基础验证

- TypeScript 与生产构建通过；现有主包大小警告仍在。
- Chromium 手机横屏模拟 1000×460：底座加载、普攻拖动时隐藏双剑并显示圆钮、松手复位、摇杆跟随和控件边界通过。
- 实际录音解码和 Heavy Dungeon 媒体播放通过（96 秒）；五章、Boss、营地、结算曲目切换通过。
- 同帧 100 次命中/拾取触发仅 3 个声音；混合事件压力检查最多 18 个声音，护盾和红装保留，解码缓存约 23.73 MiB。
- 暂停期间战斗声音被抑制，装备操作仍播放。浏览器仅有原有 favicon 404，无音频资源错误。
- 尚未在 OPPO/Via 或 iOS 真机进行听感验收；没有进行长时间跑局或额外数值测试。
