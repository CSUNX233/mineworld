# 小地图与怪物掉落调整

## 最终确认的掉落规则

- 普通怪装备掉落概率按原曲线乘 0.9，不采用 60%–80% 方案。第 1/5/25 层分别为 29.88% / 34.2% / 55.8%。精英额外掉装备由 40% 改为 36%。金币、经验、材料不变。
- 第 1–5 层仅黄色「稀有」装备的品质概率在既有调整后再乘 0.8，移除的权重转给蓝色。橙色、红色、暗金独立概率不变。精英额外掉落同样处理黄色降档；商店、打造、宝箱不变。
- Boss 每次装备总数等概率为 1、2、3 件，平均 2 件。暗金与专属武器仍每次击杀独立判定一次，但占用总数中的一件，不能额外掉出第四件。精英附加掉落不对 Boss 生效。

## 第五层 Boss

断旗奋战阶段原有的一次近战援军改成 2–4 名骷髅射手，沿 Boss 周围选合法位置，先显示地面召唤预警。沿用房间存活援军上限 4、援军 70% 生命、1.5 秒首次攻击等待和原有减半奖励规则。Boss 死亡后清理援军，存档继续沿用已召唤标记，防止重进重复召唤。

## 小地图

图集统一为金边像素风：营地帐篷、战斗双剑、试炼骷髅、宝箱、恢复石碑、出口拱门、商店钱袋、Boss 红盔。已完成房间保留类型图标，增加绿色角标；当前位置用亮色房间框和原有朝向箭头显示。图集失败时保留符号回退。

原始图与生成提示词：`art/sunlit-ui/minimap-v1/`。运行时使用 384px 无损 WebP 图集，不加载原始大图。第九枚罗盘图标保留备用，玩家继续使用精确旋转的方向箭头。

验证：TypeScript/Vite 构建；浏览器内抽取 180 次 Boss 掉落验证总数边界；调用第五层召唤控制器验证数量和远程类型；手机尺寸小地图截图检查。以上为基础逻辑验证，不代表真人平衡测试。
