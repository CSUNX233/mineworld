# 装备掉落表现

- 地面装备使用背包同源图标，包括已选定的十二套装备；旧装备回退到通用装备图集。
- 普通、魔法、稀有、史诗、传说分别对应绿、蓝、黄、橙、红，与背包品质边框一致。
- 落地弹起后缓慢上下悬浮；品质决定光柱高度、宽度、像素粒子数量和提示音。
- 红装增加红金冲击、扩散光环、专属和声音效和附近玩家的轻微镜头震动。连续掉落限制音效和震动触发频率。
- 装备延迟 0.35–1 秒允许自动拾取，红装展示时间最长。拾取需要视线畅通；失败后间隔重试，背包已满提示限频。
- 地面装备在当前楼层不再按 30 秒计时消失；离开楼层仍清除，当前不新增地面掉落存档功能。金币、药水等资源维持原有时限。
- 复用现有像素装备图、冲击与光环素材；光柱由场景面片实现，无额外实时光源。远处隐藏，低性能设备减少粒子与同时显示的完整特效数量。
- 表现模块独立于掉落概率、装备生成和战斗数值。共享纹理/面片复用，每份掉落的材质和粒子几何独立清理。

基础验证：生产构建通过；五种品质的图标选择、动画数值、远处粒子清理、重复释放和共享几何保留检查通过。尚未进行手机实机视觉验收。
