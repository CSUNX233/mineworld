# 长期天赋、九件套与死亡收割

本轮按玩家确认的方向扩展；新高难度关卡体系不在本轮制作。旧计划将红装与传奇暗金分开，本轮统一新增 `mythic` 品质，显示“暗金传说”，死亡收割为首套。现有五档装备及旧存档继续可用。

## 入口与长期成长

- 主菜单“开始游戏”进入五槽存档页，标题旁提供独立“营地天赋树”。已有活跃存档直接继续，闲置存档按此前流派开始新局；空槽只保留取名、流派选择，待确认结算仍需先领取/确认。
- 天赋树共有 46 节点：保留原 6 个流派解锁/掌握节点，新增 8 个公共主干和体魄、灵泉、锋芒、坚守各 8 节点。沿前置连线逐点修习，小点成本 1、分支终点成本 2。
- 小节点生命/法力为少量固定值与 0.5% 增益，锋芒每点攻击 0.5%，坚守每点防御 0.5；终点略高。相同属性先累加，接入真实 DerivedStats，角色面板、技能与战斗共用。
- 鼠标拖动空白处、滚轮、键盘方向键及触屏滚动查看大图，固定详情显示前置、效果与修习按钮；手机详情在图下方。
- 天赋与图鉴由五个存档共用。独立树写入只更新共享营地，保留所有冒险存档原文；进行中对局使用出发时的天赋快照，新修习下次出发生效。
- 完整通过 25 层三次取得后续进阶资格。提前撤离和旧五层规则胜利不计。只记录及展示资格，不提供尚未制作的地图入口；旧档按可验证的历史结算保守恢复次数。

保留两件、四件效果，再加入九件档。各套有九个独立底材与稳定身份，两枚戒指分别为“戒指1”和“戒指2”，对应固定装备槽、图标与名称；旧档补名称，不伪造缺失身份。重复旧戒指能保留既有两件/四件效果，但不能冒充九件毕业。

## 九件死亡收割

每件拥有固定核心机制及随机普通词条，核心重铸保留。基础数值明显高于同部位常规底材；只有专用生成入口产出，不进入商店、宝箱和普通装备池。

| 部位 | 名称 | 独立作用 |
| --- | --- | --- |
| 武器 | 冥河收割镰 | 三次有效直接命中发动群体暗影镰波 |
| 头部 | 渡魂冕 | 实际耗蓝施法时消耗魂，返还部分实付法力 |
| 胸部 | 断命丧衣 | 实际受伤后获得护盾并反击近身魂波 |
| 腿部 | 祭骨缚腿 | 静止蓄势，下一击追加伤害及移动减速 |
| 脚部 | 越冥靴 | 实际移动积蓄下一击范围追击 |
| 戒指1 | 摄魂指环·戒指1 | 命中低血量目标时追加收割斩，对 Boss 同样有效 |
| 戒指2 | 回葬指环·戒指2 | 留下延迟伤害残响，二次伤害不继续自触发 |
| 项链 | 终息沙漏 | 实际耗蓝施法消耗魂，发动群体魂爆 |
| 副手 | 引魂灯 | 消耗魂自动攻击；召唤物真实命中也能提供魂 |

任意一件即可通过直接命中和击杀收魂，HUD 显示当前魂量。两件扩大魂量与基础属性，四件加强积魂及覆盖，六件加强遗物伤害与收割门槛。九个不同身份凑齐后，九魂触发六秒死神化身，二十秒冷却，每秒发动大镰波，强化所有遗物追击。纯 Boss 战可以通过命中积魂，不依赖小怪尸体。

二次伤害走统一抗性/防御/击杀管线，但不重新触发装备命中链。有限目标数、延迟队列及特效池避免无限扩散。换层/读档不重放旧残响；读档保留魂与冷却，不重开已结束的变身。骨缚减速不使用冻结状态，避免误将 Boss 正在执行的攻击停住。

## 掉落、图鉴与表现

- 现有体系每次 Boss 击杀独立进行一次 3% 抽取，命中后九件等概率获得一件。普通幸运、品质权重、增援怪数不改变此专属抽取；小怪概率为零。原 Boss 常规掉落仍保留。
- 当前一局五次 Boss，每次最多一件，因此九件自然毕业面向未来体系；现有体系主要体验单件和低件数混搭。不会为演示修改真实掉落概率或让装备带出。
- 首次拾取以稳定 contentId 点亮共享图鉴，重复发现不重复奖励。最终 Boss 战利品在自动胜利结算前收录，避免无法走过去拾取。地面未拾取红装随本层快照保存；拾取后先移除地面实体再保存，避免复制。
- 九张独立生成的透明像素图标，统一骨白、暗金、深红、深色轮廓；接入背包、装备槽、详情、掉落，并纳入现有资源预热。
- 边框具有红金流光、脉冲和边缘火星；地面有浮动图标、旋转彩色光柱、上升魂环和瞬间冲击。减少动态效果偏好下界面停止动画。
- 九部位有各自的粗模外观，化身增加角冠、大镰、肩部轮廓和红金碎片。第一人称避开中央视野；正式 HD2D/统一成品模型仍属后续美术阶段。
- 加载提示新增渡河人九件行装、缺失钟声、倒流沙漏等传说，以及双戒、九件收集和天赋生效说明。
