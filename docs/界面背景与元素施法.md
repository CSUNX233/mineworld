# 界面背景与元素施法（2026-09-13）

上一轮音频与摇杆已提交并推送至 main：`4e60023`。本轮生成三张大幅背景和一张主线任务底板，内置 image_gen 生成，参照项目既有星火行者、深渊领主、1–5 层光照参考设计。原图与提示词保存在 `art/sunlit-ui/menu-art-v1`，可直接用作宣传素材；游戏使用 `public/assets/ui/sunlit/menu-art` 中约 0.98 MB 的四张 WebP。

- 主菜单采用全幅背景、大标题与“开始游戏 / 操作说明 / 退出游戏”三个按钮，不显示额外面板。存档和操作指南沿用原有可读面板；背景沿用主菜单图。
- 退出按钮请求关闭窗口；普通浏览器若不允许关闭，显示手动关闭标签页提示，不伪装退出成功。
- 暂停背景采用营火休息图，保留设置面板的阅读对比与滚动操作。
- 加载面板的纯色底改为行装地图图，保留实际加载进度和滚动提示。外围原有加载场景保留。
- 主线任务底板使用地图纹理，通过 CSS 裁切原图外围留白，不扩大原来的 HUD 占用区域。

左手施法同时修改火焰与光晕颜色：物理为浅金、火为橙红、冰为冰蓝、雷为蓝紫、毒为绿、暗影为紫。着色器复用同次贴图采样，将原始彩色贴图转为中性亮度后着色，避免橙色贴图乘蓝色后发黑。共享贴图本身不变；第一、第三人称继续复用原有 Sprite 池与左手挂点，不改技能伤害、消耗、冷却或碰撞判定。
