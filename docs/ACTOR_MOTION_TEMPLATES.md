# 跳跃、落地与全敌人受击模板

2026-09-13，追加到角色替换参考图阶段。本轮提供 21–24 号动作参考板和映射规格，尚未修改运行动画、伤害、控制或碰撞。查看 [参考图预览](../art/sunlit-actors/replacement-reference/preview.html)。

## 主角跳跃与落地

| 状态 | 姿态重点 | 后续接入依据 |
| --- | --- | --- |
| 起跳 | 膝盖微屈，脚踝蹬地，身体伸展 | 实际起跳事件；压身只作用于视觉，不能延迟跳跃输入 |
| 上升 | 腿部自然收起，武器握稳，披肩下垂滞后 | 离地且垂直速度为正 |
| 顶点 | 腿部展开准备下落，躯干稳定 | 垂直速度接近零，短过渡，不人为悬停 |
| 下落 | 双脚准备接地，上半身略前倾 | 离地且垂直速度为负；走下平台直接进入此状态，不先播放起跳 |
| 触地 | 脚先接触，膝盖压缩，骨盆略降 | 从离地变为着地的单次事件，不在每个着地帧重复触发 |
| 恢复 | 躯干回弹，披肩与腰灯稍后稳定 | 快速混回移动或待机；连续起跳可以立即覆盖落地表现 |

普通跳跃落地轻巧，高落差落地增加压身与少量扬尘。强度使用接地前的下降速度，并设上限；不能读取已经被碰撞清零的速度。台阶与小幅地面高度变化不重复播放重落地。坡面/平台脚底按现有地面高度对齐，表现层不改变真实位置、重力、跳跃高度或可跳过地波的阈值。

武器始终跟随手部挂点。重武器可双手稳住，但不因此增加落地锁定时间。空中施法或攻击保留现有许可规则，上半身动作可覆盖，腿部继续跳跃状态。披肩和腰灯用少量骨骼或阻尼旋转表现惯性，不做布料物理。

第一人称以手臂轻微下沉和恢复为主，保持准星与输入方向；不强制甩头、滚转镜头，也不叠加大幅落地震动。

## 主角受击

前、后、左、右四方向使用同一组受击参数，方向由真实攻击来源转换到角色局部空间。没有可用来源时采用轻微居中反馈，不能错误地使用玩家当前瞄准方向作为来击方向。

- 生命受伤：短促的局部闪白或接触火花，上半身偏转后回到当前动作。移动中的腿部继续原有步态。
- 护盾吸收：局部银色防护反馈，较轻的手臂/肩部让力，不播放与生命受伤完全相同的严重动作。
- 闪避：不播放真实受伤反馈，可沿现有闪避结果显示擦身轨迹；不能凭动画再次判定一次闪避。
- 空中受击：叠加有限的胸肩偏转，继续原有垂直运动与落地状态。
- 持续伤害：保留灼烧、毒等状态表现与实际扣血，避免每个伤害 tick 重启全身受击或镜头震动。
- 死亡：立即交给死亡状态，不播放“受击恢复站起”。已有冻结、眩晕等状态仍由游戏逻辑决定。

受击强度参考实付伤害、招式类别和目标体型，设上下限；多段攻击合并表现脉冲，不能重置整段恢复形成无限抖动。图中幅度为关键姿态示意，游戏中应减小到不影响操作的程度。

## 九类敌人受击模板

每类都包含接触、偏转、恢复，并可按来击方向调整。共享的是动作结构和参数，不要求所有网格完全一致。

| 模板 | 适用敌人 ID | 主要表现 |
| --- | --- | --- |
| light_biped 轻型人形 | zombie, skeleton, demon, orc_warrior, ruin_acolyte, ruin_geomancer, sanctum_mourner, epitaph_attendant, returning_blade, name_digger, ash_wanderer, shade_hunter, facet_mage, eye_keeper, rift_weaver, lost_soldier, banner_captain, seal_scribe, lock_arbalist | 胸肩短偏转，髋部小幅反向平衡；武器、旗和法器有有限滞后 |
| heavy_biped 重型双足 | golem, valve_overseer, chain_smith, bell_acolyte, seal_engine | 躯干反应幅度小、回弹稍沉；关节转动，硬甲不拉伸 |
| shield_guard 盾卫 | ruin_guardian, crystal_guard, linked_guard | 盾面受击时前臂让力；侧后命中身体时走躯干受击，不能把模型持盾当成新增无敌判定 |
| burdened 负重 | coffin_bearer | 主体小幅压身，棺架/背负物轻微滞后，避免大幅甩棺 |
| quadruped 四足 | ram_beast, poison_spitter | 前腿或侧腿轻微吸收，躯干偏转；撞头、毒囊挂点不脱离 |
| soft_body 软体 | slime | 局部凹陷、有限压扁与回弹；保持真实中心和碰撞体不变 |
| floating 悬浮 | fire_elemental, shadow_wraith, lich | 中央主体偏转，外层碎片/披衣滞后，维持浮动基线；巫妖按最终悬浮或双足骨架选参数变体 |
| turret 转台构装 | prism_sentry | 底座不动，仅发射头轻微偏转后混回瞄准；底座可沿原移动逻辑运动，不因模板取消移动能力 |
| boss Boss | oath_gatekeeper, furnace_regent, bellkeeper, boss, ruins_warden | 普通命中局部甲片、肩膀或核心闪动；实际破防/失衡时才播放更明显的全身动作 |

40 个注册敌人逐项映射，普通敌人 35 个、Boss 5 个。精英沿用原模板调整视觉幅度，不新造一套基础动画。友军召唤战士和射手沿用轻型骨骼参数，护卫沿用盾卫参数；友军标记与色板保持原方案。

四足毒囊、悬浮巫妖等最终骨架仍需建模确认；这里是新造型的施工约束，不要求旧程序粗模即时拥有这些骨骼。

## 判定和表现必须分离

普通受击仅改变视觉子节点，不写入真实位置、朝向、速度、寻路状态、攻击计时或房间归属。受击方向偏转后恢复到当前动画姿态，不恢复成硬编码的待机姿态。

Boss 阶段转换、冲撞、施法与真正的控制状态拥有更高优先级：普通受击只允许局部叠加或接触特效，不能取消冲撞或让攻击命中轴偏离预警。视觉“更痛”不代表新增眩晕、击退、无敌帧或减速。已有失衡/暴露事件才允许使用较大幅度动作，不能凭低血量自行开启弱点。

攻击、跳跃和受击应通过分层姿态混合共存：下半身移动/跳跃，上半身持武器/施法，末层加入受击偏移。死亡与正式控制状态按明确优先级覆盖；解除后混回当前有效状态。

## 手机性能与后续验收

每个实体保留固定大小的受击状态，预存向量和目标角度；不用每次受击创建新 Tween、Mesh、材质或全身模型副本。接触火花与扬尘进入已有 Effects 对象池。共享动画剪辑但保持每个实体独立播放状态，不能修改共享材质导致同类怪物一起闪白。

正式接入时只先检查：连续起跳、下台阶、落地立即移动、空中受击、边走边受击、持续伤害、多段攻击、Boss 冲撞/施法不断招、实际失衡、死亡不复起以及不同地面高度。确认数值、命中与输入响应保持一致后交用户实机验收。本轮未执行这些运行测试，也未替换游戏动画。
