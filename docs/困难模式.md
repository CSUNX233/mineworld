# 困难模式

营地树新增「困难模式」节点，连接破阵剑术根节点。完整通过 25 层并完成结算至少 2 次后，可免费解锁；提前撤离与死亡不计通关次数。解锁在共享营地中保留。

解锁后，每次开始新冒险显示普通/困难选择；继续已有冒险不重复询问。难度保存在 activeRun.difficulty，旧存档缺少字段视为普通。存档校验接受旧数据，不改变共享天赋或存档版本。

- 普通：现有规则全部保留。
- 困难：所有敌人（含 Boss 和援军）基础攻击乘 1.5；攻击冷却推进速度乘 1.2，并与原有动态攻击欲望相乘。移动速度、攻击预警、飞行物速度保持原样。
- 困难天然小怪：每次有奖励的击杀独立判定 0.5% 暗金死神套装掉落，不受普通装备概率、幸运或前五层黄色降率影响。成功时替代普通装备；没有普通装备也可掉落。Boss 专属武器不加入小怪池；Boss 原有暗金规则不变。无奖励增援、减半奖励召唤物仍沿用其原有防刷规则。
- 经验、生命值、金币、研究结算奖励不因困难模式额外变化。

基础验证：解锁次数门槛、不可绕过未解锁状态开困难、难度存档往返、旧存档兼容、暗金独立判定、攻击频率倍率；浏览器检查难度选择和营地树，验证援军复制不会重复叠加困难攻击倍率。未做完整通关模拟。
