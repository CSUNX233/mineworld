# 怪物深度平衡

## 本轮参数

怪物模板继续定义不同敌人的基础生命、攻击、护甲、攻速和机制；精英词缀继续在生成后单独修正生命或攻击。本轮只调整唯一的楼层倍率层，避免把同一种深度增长重复应用到模板、生成器和战斗结算。

基础楼层倍率沿用原值：生命为 `1 + 0.18 × (楼层 - 1)`，攻击为 `1 + 0.12 × (楼层 - 1)`。1–5 层因此与调整前完全一致。5 层之后再用 smoothstep 曲线逐渐加入后期修正，25 层达到上限：

| 敌人 | 25 层生命修正 | 25 层攻击修正 |
| --- | ---: | ---: |
| 普通怪 | 相对原曲线 +20% | 相对原曲线 +6% |
| Boss | 相对原曲线 +25% | 相对原曲线 +8% |

楼层输入封顶为 25。这样意外传入更深楼层时不会继续无限放大；怪物模板差异、精英额外生命和 Boss 技能伤害仍然只在各自原有位置应用一次。

## 设计理由与限制

- 前五层不增加额外压力，让新玩家先理解走位、装备和技能。
- smoothstep 的起点与终点斜率为零，避免跨过某一楼层后突然跳伤害；中段开始能明确感到深入带来的压力。
- 生命增幅略高于攻击增幅。战斗会更要求构筑成形，但不会仅靠一次失误制造过强的伤害尖峰。
- Boss 的生命修正比普通怪高 5 个百分点、攻击修正高 2 个百分点，强化每五层的检查点，同时保留现有招式提示和躲避窗口。
- 已建立基于真实游戏逻辑的固定策略模拟，联合运行护盾回复、防御减伤、闪避、吸血上限、掉落和构筑成长。协议见 [玩家模拟](PLAYER_SIMULATION.md)，机器人结果不等同于真人胜率。
- 除完整 25 层新手约 50%、熟练约 80% 外，单独要求新手前五层通过率至少 90%。先排除输入、寻路和交互缺陷，再根据楼层死亡分布调整游戏；不靠改变人物反应参数或提高开局压力凑结果。

## 批量校准调整

初始额外攻击修正为普通怪 +15%、Boss +20%。修复模拟人物的导航和预警读取后，独立种子显示熟练人物仍有较多中后期死亡。因此仅将额外攻击修正回调为 +6% / +8%，保留血量修正和前五层基础曲线。25 层相对本轮初始候选的实际伤害下降约 7.8% / 10%，并非取消深度成长。

校准批次 43001–43050：新手 28/50（56%）、熟练 38/50（76%），两组前五层均 50/50，无无效局。最终独立复核见 [模拟报告](PLAYER_SIMULATION_RESULTS.md)。
