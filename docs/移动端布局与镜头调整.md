# 移动端布局与镜头调整

本次调整局内天赋展示、移动端按键位置和普攻动作表现，不改变装备数值、攻击冷却、伤害与命中判定。

## 操作

- 横屏局内天赋去除获取节奏说明，标题与点数并排；核心及两条分支并排展示，列表独立滚动，底部操作固定。
- 暂停菜单 → 操控 → 自定义按键位置：拖动移动、攻击、四个技能、背包、视角、技能配置、暂停和交互按键。保存、取消或恢复默认；工具栏可以收起以调整它下方的按钮。
- 布局仅保存在当前设备的 localStorage 独立键 mineworld_touch_layout_v1，不修改角色存档。横竖屏分别保存，按屏幕比例定位并限制在安全区域。旋转屏幕会取消当前未保存编辑。
- 第三人称在场景空白处双指张开拉近、合拢拉远，沿用滚轮的 3–9 距离限制。按钮上的触摸不参与缩放，第一人称不缩放。结束双指手势后，重新触摸再进行单指转向，避免残留手指导致跳镜头。
- 普攻视觉采用快速挥出、缓慢收回，近战使用交替斜向挥击，法杖保持前向动作；触屏长按判定延迟从 120 ms 缩短到 70 ms，拖动瞄准与松手攻击仍保留。未重新启用刀光贴图。

## 基本验证

环境：http://127.0.0.1:5173/，已有 Chromium / Playwright，触屏模拟 844×390、667×375、390×844；1280×720 仅检查宽窗口布局。Browser plugin not available，使用已有 Playwright，无额外安装。

| 检查 | 结果 |
| --- | --- |
| 构建与 TypeScript | npm run build 通过；原有大 bundle 提示仍存在 |
| 页面加载及目标面板 | 游戏、天赋、暂停及编辑器均正常显示，无空白或框架错误遮罩 |
| 横屏密度 | 首屏核心与两分支并排，无获取节奏段落；844×390 下列表可视高度约 201 px |
| 布局交互 | 攻击键向左拖动并保存，游戏中的实际边界随之移动；取消可返回暂停 |
| 横竖屏 | 竖屏使用独立默认布局，按键编辑器可打开、取消 |
| 双指缩放 | CDP 触摸事件使第三人称距离由 6 降至约 5.127；第一人称距离不变 |
| 运行时异常 | 本轮捕获的 pageerror 为 0 |

操作链：新游戏 → 第三人称 → 天赋 → 暂停操控 → 拖动攻击键并保存 → 继续 → 再次编辑取消 → 竖屏编辑取消 → 第三人称双指手势 → 第一人称双指检查。

截图与临时检查脚本：.playwright-cli/mobile-controls-qa/、.playwright-cli/mobile-controls-qa.cjs。未进行真实 Android / iOS 设备长时间战斗测试；实际手感仍需本人在手机验收。未重新打包 APK，也未推送部署。
