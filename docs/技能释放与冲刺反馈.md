# 技能释放与冲刺反馈

技能成功后仅保留对应按键亮起一次，取消成功和失败文字。冷却误按使用独立短音效 skillNotReady，间隔至少 550 ms、最多一个并发；触屏冷却按钮仍允许把失败尝试交给游戏逻辑，不消耗法力或重设冷却。

左手施法姿态和元素能量放大；成功释放出现短地面脉冲，防御类稍长；近战和冲刺使用不同动作。冲刺与旋风技能使用独立音效事件和较高优先级，沿用已授权素材，保持全局混音数量限制。

冲刺改为固定方向的短爆发，不再叠加普通移动输入或经过步行加速。当前速度 17、持续 0.18 秒保持不变，空地单次移动约 3.06 米；最后一帧按剩余持续时间处理，结束后恢复移动输入，不额外滑行。仍使用原来的分步墙壁及屏障碰撞。新增短尾迹根据实际移动位置生成，沿用 Effects 对象池及现有总粒子上限。

本次没有改变伤害倍率、技能耗蓝、冷却、目标筛选或无敌条件；调整了实际位移响应，属于手感修正，并非只改动画。

## 基本验证

- npm run build 通过（原有大 bundle 提示保留）。
- Chromium / Playwright，844×390 触屏模拟；Browser plugin not available，使用已有 Playwright。
- 30 / 60 / 120 fps 下，0.18 秒空地冲刺结果均为 3.06 米、结束速度 0（无移动输入）。
- 合成墙体检查：墙位于 z=7，角色停止在 z≈6.558，没有穿越。
- 游戏里真实触屏按下冲刺键后出现成功提示；再次按下冷却键出现冷却提示；法力不足时出现法力提示。捕获 pageerror 为 0。
- 反馈提示移到屏幕上方，避免与进层标题重叠。截图及临时脚本位于 .playwright-cli/skill-feedback-qa/ 和 .playwright-cli/skill-feedback-qa.cjs。
- 尚未做实际手机长时间战斗测试，也未推送或重新生成 APK。


## 播报调整

装备拾取、房间和其他冒险消息使用 AnnouncementQueue 的同一个横幅，淡入淡出，最多排队 8 条。普通战利品合并显示，旧房间名替换为最新房间；低优先级待播超过 7 秒不再显示，避免过时信息。进入新楼层会清空上一层待播内容。

文字使用实际品质色。黄色轻弹、橙色中等弹出与短震动、红色和暗金更强，并优先显示；仅晃动文字，遵守系统减少动态效果偏好。普通受击不再反复覆盖播报。此前红装已有的镜头震动未额外加强。

基本验证：844×390、390×844 Chromium 触屏模拟；成功图标动画存在、没有技能提示文字；冷却误按触发 skillNotReady；20 次普通拾取合并成一条且与最新房间排队，红装先显示，画面可见播报数始终为 1。页面异常 0，构建通过。此次验证覆盖并取代前节旧的文字提示断言；实际手机及混战音量感受待验收。

截图与临时检查脚本：.playwright-cli/announcement-qa/、.playwright-cli/announcement-qa.cjs。
