# 开场剧情：弦外之音

最终使用六张画面：街头相遇；受伤坚持与三日期限；父亲赌债；吉他与传说；旋律异变；遗迹苏醒。取消独立的第三张催债画面，相关对白合并进第二幕。吉他画面已修正多余手臂。

首次玩家点击开始游戏后自动建立「初入深渊」普通难度剑术冒险，不经过存档和营地菜单。六幕提供文字、点击继续、跳过、轻微推近与淡入。完整播放或跳过使用相同结束流程，保存后进入遗迹第一层，再显示之前约定的首次视角选择。

已有存档或已完成首次体验的玩家保留原来的开始→存档入口，不覆盖旧冒险。剧情前保存 openingPending 标记；中途关闭后可以从存档重新播放未完成的开场。播放期间不保存尚未初始化的地牢快照；保存失败保留原重试机制。

素材按当前幕加载，并预取下一幕，避免一次阻塞下载整套。文字独立于图片加载，图片失败仍能阅读、继续或跳过。手机横屏为主要布局，兼容竖屏，支持键盘操作和减少动态效果偏好。

原图、内置 imagegen 提示词与六幕预览：`art/opening-story-v1/`。运行时六张 WebP：`public/assets/story/opening/`。prompts.json 保留最初七幕生成记录，sources.json 为最终六张选用清单。

基础验证：六幕翻页、完成后进入第一层、跳过仅触发一次结束回调、再次开始恢复存档入口、手机横屏截图、正式构建。未添加配音或新录制吉他音乐。
