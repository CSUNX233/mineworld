# 25 层通关阻塞修复

新版（地图生成版本 7）20 / 25 层的 `room-4` 缺少 required 标记。玩家清理后没有写入对应 completedObjectives，尽管本层 portalReady 为真，结算仍缺少 50 个主线目标中的两个。终层出口仍显示继续第 26 层，advanceFloor 调用胜利结算后被校验拒绝。

修复保持地图坐标、怪物与奖励不变，将这两个房间恢复为主线。Encounter 更新时对旧档进行有限补记：当前 20 / 25 层只补 cleared 中已有的 room-4；已推进到 21 层之后且记录过 20 层 Boss 目标时，补记 20-room-4。不会补记未击败的最终 Boss、无关目标或伪造历史投入样本，不重复发放清房奖励。

25 层出口按钮显示通关结算；不满足条件时给出说明，不调用必然抛错的结算。正常击败最终 Boss 并完成主线后依旧自动显示通关界面。恢复旧存档后继续游戏即可触发检查，无需重开或删除数据。

验证：tests/final-victory.test.mjs 覆盖实际生成的 1–25 层主线目标、500 研究经验结算、重复结算保护、旧 25 层卡档恢复、旧 20 层提前结算恢复和未完成目标拒绝。TypeScript 与生产构建通过。未使用玩家实际存档或手机实机重放。

已生成的 APK / H5 1.0.2 不会自动包含后续源码修复，分发前需要重新构建新版本。

发布包：Android 1.0.3 / versionCode 4 包含本次修复，沿用原签名。旧 1.0.2 APK 和 H5 ZIP 保留但不含修复。
